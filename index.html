AURA — Fine Dining UX & Implementation

01 / Overview

AURA is a luxury restaurant concept focused on creating a digital experience that mirrors the atmosphere of high-end dining. The project addresses common restaurant site friction: buried menus, difficult reservation paths, and uninspired mobile UI.

02 / The Problem

Most restaurant websites suffer from heavy PDF menus, unoptimized mobile interfaces, and broken third-party booking embeds that cause drop-offs.

03 / Wireframes & Flow

[ Wireframe Flow: Landing Page → Filterable Menu → Modal Reservation ]

04 / Final Implementation

Built with lightweight HTML5, CSS Grid for responsive menu cards, and clean JavaScript for instant booking date selections.
