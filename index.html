01 / CASE STUDY

AURA Fine Dining Web Experience

01 Overview

AURA is a self-initiated restaurant UI/UX design project aiming to bridge editorial luxury visual identity with intuitive online table reservations and menu exploration.

02 Problem

Traditional restaurant websites suffer from cluttered menus, PDF links that fail on mobile devices, and complex multi-step booking flows that lead to lost reservations.

03 Key Solutions

  • Mobile-first menu browsing with category pills and dietary filters.
  • Direct 2-click reservation flow integrated into the navigation.
  • High-contrast editorial typography ensuring WCAG AA readability.

04 Responsive Design & Implementation

Built with pure semantic HTML, custom CSS grid layouts, and zero heavy dependencies for lightning-fast page speed.

02 / CASE STUDY

PULSE AI Dashboard System

01 System Vision

An analytics dashboard tailored for machine learning ops teams who require real-time visibility into model latency, token consumption, and prompt optimization.

02 Information Hierarchy

High-density data requires visual breathing room. PULSE utilizes strict contrast tiers, sparklines, and status badges to draw attention to system anomalies immediately.

03 Accessibility Standards

All chart colors pass color-blindness simulation tests, utilizing double-encoding (color + text labels) for critical metric statuses.

03 / CASE STUDY

Fintech Checkout Friction Reduction

01 Problem & Audience

Mobile users experienced a 42% drop-off on step 3 of a multi-page checkout flow due to unnecessary form fields.

02 Wireframing & Transformation

Consolidated 5 separate steps into 1 smart, context-aware payment sheet, prioritizing Apple Pay/One-Click solutions.
